## ▍ ARCHITECTURE

How I actually put things together — and where the cloud *isn't*:

```text
                    ┌─────────────────────┐
                    │   PRESENTATION      │   React · Next.js · Tailwind
                    │   tier              │   state, routing, rendering
                    └──────────┬──────────┘
                               │  typed contracts
                    ┌──────────┴──────────┐
                    │   BUSINESS LOGIC    │   Node · Express · .NET
                    │   tier              │   validation, auth, services
                    └──────────┬──────────┘
                               │  parameterised queries
                    ┌──────────┴──────────┐
                    │   DATA              │   MySQL · MongoDB · SQLite
                    │   tier              │   schema, indexes, migrations
                    └──────────┬──────────┘
                               │
                    ┌──────────┴──────────┐
                    │   YOUR MACHINE      │   ← the data never leaves here
                    └─────────────────────┘
```

**What I optimise for:** predictable queries, honest error handling, small dependency trees, and an app that still works when the Wi-Fi doesn't.
